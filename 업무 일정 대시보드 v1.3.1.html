구글 드라이브 연동 설정

구글 스프레드시트 실시간 동기화 설정 방법 (약 1분 소요):
  1. 구글 스프레드시트 (새 탭 열기)에 접속합니다.
  2. 상단 메뉴 [확장 프로그램] -> [Apps Script]를 클릭합니다.
  3. 아래 [배포용 코드 복사] 버튼을 누른 뒤, 편집창의 기존 내용을 지우고 붙여넣기 후 Ctrl + S 저장
  4. 우측 상단 [배포] -> [새 배포] -> 유형: 웹 앱 선택
  5. 설정: 실행자 [나], 액세스 권한 [모든 사용자(Anyone)] 필수 선택 후 [배포] 클릭
  6. 생성된 웹 앱 URL을 아래 입력창에 넣고 [연결 테스트 & 동기화]를 누르면 끝!
클립보드에 복사되었습니다!
PC용 구글 드라이브(Google Drive for Desktop) 파일 직접 연결:

PC에 구글 드라이브 앱이 설치되어 있다면(예: G:\내 드라이브), 구글 드라이브 내의 JSON 파일을 직접 선택하여 등록 시마다 자동 덮어쓰기 저장할 수 있습니다.
