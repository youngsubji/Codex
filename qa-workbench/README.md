# 개인용 QA Workbench

`index.html`을 Chrome 또는 Edge에서 열어 사용합니다. 설치나 서버 실행은 필요하지 않습니다. HTML 파일 하나에 스타일, 글꼴, 실행 스크립트, 안내 이미지, Excel/PPT 양식과 예시가 포함되어 있습니다.

## 기본 로고와 선택 색상

좌측 상단에는 A.I.matics 브랜드 로고와 `(QA)` 표기가 기본으로 표시됩니다. 로고 이미지를 HTML 안에 직접 포함하여 인터넷 연결이나 브라우저 저장 설정 없이 표시합니다. 로고 선택, 로고 파일 입력, 로고 포함 HTML 저장 버튼과 이전 사용자 로고 설정은 사용하지 않습니다.

채팅 첨부 이미지의 원본 파일 데이터가 이 작업 공간에 제공되지 않아, 같은 브랜드의 [공개 로고 원본](https://img.newspim.com/news/2019/12/02/1912020945426410.jpg)을 수정 없이 사용하고 `(QA)` 문자를 옆에 배치했습니다. 따라서 첨부 이미지 파일 자체를 그대로 내장한 것은 아닙니다.

메뉴·탭·필터·홈 도구 카드·선택 결과의 강조색은 `#36c25e`입니다. 배경은 불투명도 14%, 테두리는 42%, 마우스 올림은 8%를 사용합니다. 입력 모드의 선택 표시선은 80%, 키보드 포커스는 55%입니다. 글자는 대비를 유지하도록 짙은 초록색을 사용합니다. 작업 저장은 기존 전체 작업 JSON 저장·불러오기를 사용하세요.

## 원본 구성 분석

원본: https://qaworkbench.pages.dev/tools/?lang=ko

기준 버전: 1.8.36. 제공된 화면과 공개 HTML/CSS/JavaScript를 근거로 개인용 단일 파일을 구성했습니다. 원본의 스크립트 순서와 도구 간 데이터 연결을 유지했습니다.

| 구성 | 도구 및 역할 |
|---|---|
| 테스트 설계 | 요구사항 기반 테스트 케이스 초안, 경계값 분석, Pairwise/전체 조합, 결정 테이블 |
| 테스트 데이터 | API 요청용 데이터, 필드별 정상·예외 데이터, 샘플 문자열·날짜·이메일 등 |
| 데이터 검증 | JSON 비교, JSON Schema 검증 |
| 진단 도구 | PC/Android 로그·리소스 수집용 스크립트 생성 |
| 레퍼런스 | QA 체크리스트, HTTP 상태 코드 검색 |
| 작업 관리 | 전체 작업 JSON 저장·불러오기, 브라우저 자동 저장 설정 |
| 홈 | 12개 도구의 입력·결과 예시와 도구 진입 |

왼쪽 메뉴, 도구별 입력/결과 화면, 상단 전체 작업 관리, 한·영 언어 전환, 파일 내보내기 구조를 유지했습니다. TC는 직접 입력 화면을 기본으로 표시합니다. 진단 스크립트는 생성·다운로드하며, 사용자 PC의 명령을 HTML 안에서 실행하지 않습니다. API 테스트 데이터 도구는 요청용 데이터를 생성하며 실제 API 호출을 실행하지 않습니다.

## 개인용 변경

- 제목과 로고 영역을 A.I.matics (QA)용으로 변경하고 기본 로고를 내장했습니다. 로고 선택 관련 항목은 제거했습니다.
- 하단 문구: `Created by Youngsub Ji`.
- 사이트 사용 통계용 `usage.js`, `usage.css`, 측정 ID를 제외했습니다.
- 정적 실행 자원을 파일 안에 넣었습니다. 기본 도구 실행에는 인터넷 연결이 필요하지 않습니다.
- 브라우저 저장 키에 개인용 접두어를 적용했습니다.
- 복사 권한이 없는 환경에서는 원본의 직접 복사 대화상자를 사용합니다.
- 외부 사용 가이드, 개인정보 안내, 문의, HTTP 표준 문서 링크는 온라인 원본으로 연결됩니다.

## 지원 범위와 확인 결과

PDF 직접 읽기와 이미지 OCR은 별도 엔진이 필요해 포함하지 않았습니다. PDF의 텍스트는 복사하여 요구사항에 직접 입력하세요. 명세 문서 가져오기는 XLSX/PPTX를 지원합니다. 이미지가 포함된 Office 문서는 텍스트 부분만 처리합니다.

브라우저 저장 데이터는 사용 중인 브라우저와 파일 위치의 영향을 받을 수 있습니다. 장기 보관할 작업은 전체 작업 JSON으로 다운로드하세요.

JavaScript 구문, 12개 메뉴와 설정 화면 초기화, 주요 생성·검증 처리, 잘못된 경계값 입력 거부, 작업 파일 형식 검증, CSV 수식 방어, XLSX ZIP 헤더, 고정 로고 이미지, 로고 선택 관련 항목 제거, 홈 미리보기·메뉴 이동·언어 전환을 DOM 기반으로 점검했습니다. 메뉴·입력 모드·필터·도구 카드 선택 시 계산된 CSS 색상이 지정된 초록색 배경·테두리와 일치하는 것도 점검했습니다. 실제 브라우저의 화면 비교, 모바일 표시, 파일 선택과 다운로드 완료, 클립보드 권한은 검증하지 못했습니다. DOM 점검은 실제 브라우저 시각 검증을 대신하지 않습니다.

원본 서비스의 공개 클라이언트 코드를 사용한 개인용 재구성 파일입니다. `Created by Youngsub Ji`는 요청하신 개인용 표시이며 원본 코드 전체의 저작자 표시를 의미하지 않습니다. 원본의 이용약관과 사용 권한 범위에 맞게 사용하세요. JSZip의 원본 라이선스 주석을 유지했습니다.
